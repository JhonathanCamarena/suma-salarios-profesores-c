# Suma de Salarios de Profesores

## ¿Qué problema resuelve?
Calcula el total de salarios de un grupo de profesores. El usuario indica cuántos profesores va a ingresar, escribe el salario de cada uno y el programa muestra la suma total.

## Tecnologías
- Lenguaje **C**
- Ciclo `while` con variable de control y acumulador
- Librería estándar `stdio.h`

## ¿Cómo se instala y ejecuta?
1. Instala un compilador de C (por ejemplo GCC / MinGW, Code::Blocks o Dev-C++).
2. Descarga el archivo `salarios_profesores.c`.
3. Compila y ejecuta:
```bash
gcc salarios_profesores.c -o salarios
./salarios        # en Windows: salarios.exe
```

## Ejemplo de uso
```
¿Cuantos profesores desea ingresar?: 3
Ingrese el salario del profesor 1: 800
Ingrese el salario del profesor 2: 900
Ingrese el salario del profesor 3: 1000
El total de salarios de los 3 profesores es: 2700.00
```
